# CHANGELOG

## [0.1.0] - 2026-08-23

### Added

- Implemented the Friedman and Miyake (2004) abstract-shape identity negative-priming protocol.
- Added balanced deterministic prime-probe pair generation for no-distractor, control, and negative-priming conditions.
- Added Chinese participant instructions, reference-aligned timing, keyboard response semantics, and trigger mapping.
- Added human, QA, scripted simulation, and sampler simulation profiles.
- Added literature selection, protocol audit, parameter mapping, and stimulus mapping artifacts.

### Changed

- Adapted the original left/right response buttons to `F`/`J` keyboard responses.

### Fixed

- None in the initial release.
